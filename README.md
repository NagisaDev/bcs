## Технологии
* **Модель:** YOLOv8 (Instance Segmentation)
* **Аналитика:** OpenCV, Pandas, NumPy
* **Интерфейс:** Streamlit
* **Железо для обучения:** Поддержка NVIDIA CUDA (протестировано на GTX 1080)

## 📦 Установка

1. Склонируйте репозиторий:
```bash
git clone <ваша_ссылка_на_github>
cd blood-cell-segmentation

Установите зависимости из файла requirements.txt
pip install -r requirements.txt

Для запуска дашборда выполните в терминале команду:
streamlit run app.py
```
